# Decision: one plugin, `flagpole-tools`, and the honest reason for it

- **Problem / trigger**: none, in the ordinary sense — and that is the point of writing this down. A plugin exists to get the same components into **more than one repository**. There is one repository here. The real trigger is the learning goal stated in `PROMPT.md`: this project is a demonstration of *which* Claude Code mechanism to reach for, and a mechanism nobody builds cannot be judged. So it is built, once, small, and labelled.
- **Alternative rejected**: leaving everything in `.claude/`, which is what a single repository should do and what this repository did for five features. Also rejected: **copying** the components so both `.claude/` and the plugin have them — two sources of truth, and the first edit to one makes the other a lie. They were moved.
- **Limits**: three skills and two agents — the *procedures* for running Flagpole (`deploy-local`, `security-scan`, `e2e`) and the two agents those skills delegate to. `/add-flag-field` and `api-conventions` stayed behind: they are knowledge about this codebase, not procedures someone with a second repository could run. Every hook stayed behind too, for a stronger reason — a plugin can be disabled with one command, and a guard that can be switched off is not a guard. Enforcement lives with `permissions.deny`, in `.claude/settings.json`.
- **Not done**: no `commands/`, no `hooks/hooks.json`, no `.mcp.json` inside the plugin (the two MCP servers are project-scoped in `.mcp.json`, where a reader looks for them); no second plugin; no publishing to a remote marketplace — the marketplace is this repository, served from `.claude-plugin/marketplace.json`. If Flagpole ever gains a second repository, that is the signal to publish it properly.
- **Cost, stated plainly**: every component is now namespaced (`/flagpole-tools:deploy-local`, `Agent(flagpole-tools:deploy-verifier)`), which meant editing every cross-reference in the skills, `CLAUDE.md`, `docs/claude-code/skills.md` and `agents.md`. `claude plugin details` reports **~510 tokens added to every session** for five components nobody may invoke. For one repository that is a bad trade, and the page that explains the mechanism says so.
- **Verification** (2026-09-03): `claude plugin marketplace add ./` then `claude plugin install flagpole-tools@flagpole-local` then `claude plugin details flagpole-tools` — inventory reports Skills (3), Agents (2), Hooks (0), and the projected always-on cost above.
