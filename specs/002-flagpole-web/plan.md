# Implementation Plan: Flagpole Web (login, flag table, audit log)

**Branch**: `002-flagpole-web` | **Date**: 2026-09-02 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/002-flagpole-web/spec.md`

## Summary

A two-page single-page application: sign in with OIDC Authorization Code + PKCE against Dex, list flags with `dev`/`prod` tabs (operators toggle, set rollout and create flags; viewers see the same controls disabled), and read the audit log with a flag filter and cursor paging. Types come from the 001 OpenAPI contract, so UI and API cannot drift. A local dev stack (docker compose) runs Dex so login and end-to-end tests work offline.

## Technical Context

**Language/Version**: TypeScript 5.x, Node 24 (Vite 8 requires ≥ 20.19)

**Primary Dependencies**: Vite 8.2, React 19.2, `oidc-client-ts` 3.5 (PKCE is the default for `response_type: code`), `openapi-typescript` 7.13 + `openapi-fetch` 0.17 (typed client generated from `specs/001-flagpole-api/contracts/openapi.yaml`). No router: two views selected by state plus a `/callback` path check (research F4). No UI framework; hand-written CSS.

**Storage**: none in the browser. The token lives in memory (`InMemoryWebStorage`, FR-003); no `localStorage`, no cookies.

**Testing**: Vitest 4.1 + `@testing-library/react` 16.3 (+ explicit `@testing-library/dom`, `user-event`, `jest-dom`, `jsdom` 30) for components; `@playwright/test` 1.62 for end-to-end against the dev stack, headless, HTML report in `frontend/playwright-report/`.

**Target Platform**: desktop browsers ≥ 1024 px; served by Vite in dev and as static files behind the ingress in the cluster (feature 005).

**Project Type**: web application frontend (`frontend/`), plus the local dev stack (`docker-compose.dev.yaml` at the repo root) that this feature introduces.

**Performance Goals**: SC-002 (save reflected within 1 s locally); no other targets. Measured, never asserted (constitution III).

**Constraints**: same-origin `/api` in every environment (Vite proxy in dev, ingress path in the cluster — feature 005 must route `/api` on the web host to `flagpole-api`, a hand-off recorded here), so no CORS for the API; Dex needs `web.allowedOrigins` for the token exchange. Dex 2.45.1 has **no** `end_session_endpoint`, so sign-out drops the token locally instead of calling `signoutRedirect()` (research F2). Every interactive element carries `data-testid` (FR-012).

**Scale/Scope**: 2 views, ~10 components, 2 static users, ~10 flags.
